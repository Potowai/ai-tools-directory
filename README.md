# AI Tools Directory

A curated directory of AI tools — what each one does, who it is for, and when it is
actually worth using.

## What it does

- Searchable and filterable catalogue
- Detail pages per tool
- Responsive, dark-mode friendly
- Deployed through OpenClaw

## Stack

- Plain HTML, CSS and JavaScript — no build step
- Tailwind CSS for styling
- Deployed via OpenClaw

## Local preview

```bash
python3 -m http.server 8000
```
